Как сохранить программы при переустановке Windows

Установленные программы нельзя надёжно перенести простым копированием папки Program Files: приложения используют реестр, службы, драйверы и общие компоненты. Поэтому перед чистой установкой нужно сохранить список приложений и подготовить официальные установщики.

Сначала составьте список

RePC сканирует пользовательские приложения и исключает многие системные Runtime-компоненты. Для программ, доступных в каталоге WinGet, формируется план повторной установки. Остальные остаются в отчёте как ручные задачи.

Сохраните данные отдельно

Список программ не заменяет резервную копию документов и настроек. Выберите нужные папки, сохраните паспорт .repc на внешний накопитель и проверьте его до удаления старой Windows.

После чистой установки

Сначала обновите Windows, затем восстановите личные файлы и устанавливайте программы из официальных источников. Не копируйте исполняемые файлы из случайных архивов. Лицензионные приложения могут запросить вход или повторную активацию.
